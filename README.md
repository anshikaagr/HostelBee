# HostelBee
Hostel Bee is a smart hostel management web platform designed to improve communication, safety, and daily operations within college hostels. It provides a centralized system where students and wardens can interact efficiently through dedicated dashboards.

Features:Secure Student Login( using institutional email ID)
Student Dashboard for:
 Raising complaints (maintenance, hygiene, etc.)
   Emergency alerts (medical/fire situations)
   Viewing important hostel notices
Warden Dashboard (planned):
   Monitor and manage student complaints
   Respond to emergencies in real-time
   Broadcast announcements

Traditional hostel systems lack real-time communication and structured complaint management. Hostel Bee addresses this by:

* Reducing response time during emergencies
* Digitizing complaint tracking
* Improving transparency between students and administration

Tech Stack
* HTML
* CSS
* JavaScript

Built as part of a college ideathon project to create safer and smarter hostel environments.
